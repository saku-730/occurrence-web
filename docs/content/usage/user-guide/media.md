## 画像のアップロード

オカレンスの登録画面または編集画面からファイルを追加できます。アップロードしたファイルはGarageに保存され、オカレンスにはメディアURIとして紐付きます。

## 対応形式

対応する形式は以下です。ファイルの拡張子だけでなく、実データのMIME typeも検証します。

- 画像: JPEG、PNG、WebP
- 音声: MP3、WAV、M4A
- 動画: MP4、MOV

## ファイルサイズ制限

画像、音声、動画はいずれも1ファイルあたり1000MBまでアップロードできます。上限を超えるファイルは保存されません。

## ライセンス

添付ファイルの利用条件は、紐付けるオカレンスのライセンス情報として管理します。公開前に、ファイルを共有・再利用できる条件を確認してください。

## 撮影者・作成者

アップロードしたユーザーはメディアの所有者として保存されます。撮影者やファイル作成者がアップロード者と異なる場合は、オカレンスの項目や注記に記録してください。

## 画像の削除

編集画面では、オカレンスからメディアの紐付けを解除できます。メディア本体を削除するには、アップロードした本人が明示的に削除します。ほかのオカレンスから参照されているメディアは削除できません。
