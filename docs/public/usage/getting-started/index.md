# Getting Started<no value>

Bio Databaseでオカレンスデータを登録、確認、公開するまでの基本的な流れを説明します。

## アカウント作成

メールアドレスを使ってアカウントを作成します。仮登録メールに記載されたリンクから本登録を完了します。

## ログイン

作成したメールアドレスとパスワードでログインします。データの登録、編集、削除にはログインが必要です。

## 最初のオカレンス登録

データ登録画面で項目名と値を入力します。分類を指定する場合は、GBIF Backbone Taxonomyの候補から選択できます。

## 登録したデータの確認

登録後はデータ詳細画面で、入力した項目、作成者、作成日時、添付ファイルを確認できます。

## 検索

データ検索画面から、項目名と値を条件として登録済みのオカレンスを検索します。

## 編集・削除

自分が作成したオカレンスは、詳細画面から編集または削除できます。

## 公開範囲の設定

登録時に公開範囲を設定します。公開データは誰でも閲覧でき、非公開データは作成者のみが閲覧できます。
