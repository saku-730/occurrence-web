# Search<no value>

## キーワード検索

データ検索画面で、項目名と検索したい値を指定します。入力した値と一致するオカレンスを検索できます。

## 分類群による検索

分類を検索条件に指定すると、GBIF Backbone Taxonomyに基づく分類群を対象にオカレンスを絞り込めます。

## 日付による検索

記録日、作成日時、更新日時などの日付を持つ項目を条件として、対象となるオカレンスを検索できます。

## 場所による検索

国、自治体、産地、緯度・経度などの位置情報を持つ項目を条件として検索できます。

## ページネーション

検索結果は複数ページに分けて表示されます。次のページを選択すると、続きの検索結果を表示できます。

## 検索結果の見方

各行にはオカレンスの主要情報、作成者、作成日時、更新日時、公開範囲が表示されます。行を選択すると詳細画面を開けます。
