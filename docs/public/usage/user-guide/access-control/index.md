# Access Control<no value>

## 公開データ

公開として登録したオカレンスは、ログインしていない利用者を含めて閲覧できます。公開オカレンスに紐付くメディアも閲覧できます。

## 非公開データ

非公開として登録したオカレンスは、作成者以外には検索結果と詳細画面に表示されません。非公開オカレンスにのみ紐付くメディアも同じ条件で保護されます。

## 作成者

オカレンスを登録したログインユーザーが作成者として記録されます。作成者情報はバックエンドが自動で設定するため、登録時に変更できません。

## 閲覧可能範囲

公開オカレンスは誰でも閲覧できます。非公開オカレンスは、そのオカレンスの作成者だけが閲覧できます。

## 編集可能範囲

オカレンスを編集・削除できるのは作成者です。添付メディアも、アップロードしたユーザーだけが削除できます。
