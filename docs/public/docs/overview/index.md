# Overview<no value>

## 概要

Bio Databaseは、生物オカレンス情報を構造化して登録、検索、共有するためのWebアプリケーションです。オカレンスのRDFデータ、ユーザー・認証情報、添付メディアを役割ごとに分けて管理します。

## フロントエンド

Next.jsを使用して、データ登録、検索、詳細表示、編集、ユーザー操作の画面を提供します。

## APIサーバー

Rustで実装したAPIサーバーが、認証、入力検証、オカレンスのRDF変換、アクセス制御を担当します。

## ユーザー・認証情報

PostgreSQLでユーザー、セッション、パスワードリセットトークン、メディアのメタデータを管理します。

## RDFデータストア

Apache Jena Fusekiに、オカレンス、語彙、分類群のRDFグラフを保存します。APIサーバーはSPARQLを使って保存、取得、検索を行います。

## メディアストレージ

GarageをS3互換オブジェクトストレージとして使用し、画像、音声、動画などのファイル本体を保存します。

## 分類群データ

GBIF Backbone TaxonomyをRDFへ変換し、約20GB規模の分類群データとしてFusekiへ投入します。分類候補の表示と分類群URIの記録に利用します。

## 公開基盤

nginxをリバースプロキシとして使用し、Cloudflare Tunnelを経由して外部へ公開します。
