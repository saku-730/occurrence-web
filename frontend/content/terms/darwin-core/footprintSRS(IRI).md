# footprintSRS

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/footprintSRS`

ラベル
`Footprint SRS (IRI)`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

The ellipsoid, geodetic datum, or spatial reference system (SRS) upon which the geometry given in dwc:footprintWKT is based.

- 日本語訳 -

範囲の空間参照系を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

通常の文字入力では基本的に使用しません。外部リソースの URI を値として登録・編集する必要がある場合に使用します。

## 関連用語
