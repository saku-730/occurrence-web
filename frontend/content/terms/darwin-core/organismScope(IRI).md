# organismScope

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/organismScope`

ラベル
`Organism Scope (IRI)`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

A description of the kind of dwc:Organism instance. Can be used to indicate whether the dwc:Organism instance represents a discrete organism or if it represents a particular type of aggregation.

- 日本語訳 -

生物個体の範囲を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

通常の文字入力では基本的に使用しません。外部リソースの URI を値として登録・編集する必要がある場合に使用します。
