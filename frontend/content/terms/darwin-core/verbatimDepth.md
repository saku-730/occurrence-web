# verbatimDepth

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/verbatimDepth`

ラベル
`Verbatim Depth`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

The original description of the depth below the local surface.

- 日本語訳 -

測定結果に関する原記載どおりの水深を記録するための用語です。

## 説明

原記載どおりの水深の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で原記載どおりの水深を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:measurementValue`：測定値
