# subfamily

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/subfamily`

ラベル
`Subfamily`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

The full scientific name of the subfamily in which the dwc:Taxon is classified.

- 日本語訳 -

対象の分類群に関する亜科を記録するための用語です。

## 説明

亜科の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で亜科を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:scientificName`：学名
- `dwc:taxonID`：分類群識別子
- `dwc:taxonRank`：分類階級

## 別名（日本語）

- 亜科
