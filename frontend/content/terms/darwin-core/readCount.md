# readCount

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/readCount`

ラベル
`Read Count`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

The number of reads obtained for a processed dwc:NucleotideSequence during a dwc:NucleotideAnalysis.

- 日本語訳 -

メディア又は配列データに関するリード数を記録するための用語です。

## 説明

リード数の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面でリード数を記録する必要がある場合に、項目名として選択して値を入力します。
