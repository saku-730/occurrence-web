# assertionUnit

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/assertionUnit`

ラベル
`Assertion Unit (IRI)`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

A unit associated with the value in dwc:assertionValue.

- 日本語訳 -

主張単位を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

Bio-Database では assertion 関連の情報を扱わない方針のため、データ登録・編集画面では使用しません。

## 関連用語

- `dwc:assertionUnit`：主張単位
- `dwc:scientificName`：学名
- `dwc:occurrenceID`：オカレンス識別子
