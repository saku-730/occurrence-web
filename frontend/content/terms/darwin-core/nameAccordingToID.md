# nameAccordingToID

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/nameAccordingToID`

ラベル
`Name According To ID`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

An identifier for the source in which the specific taxon concept circumscription is defined or implied. See dwc:nameAccordingTo.

- 日本語訳 -

対象の分類群に関する名前用法の準拠先識別子を記録するための用語です。

## 説明

名前用法の準拠先識別子の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で名前用法の準拠先識別子を記録する必要がある場合に、項目名として選択して値を入力します。
