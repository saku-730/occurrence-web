# Agent

## 基本情報

IRI
`http://purl.org/dc/terms/Agent`

ラベル
`Agent`

種別
`Class`

目的語の形式: クラス

## 定義

- 原文 -

A resource that acts or has the power to act.

- 日本語訳 -

行為者を表すクラスです。

## 説明

行為者に属する情報をまとめるための RDF クラスです。

## Bio-Databaseでの使い方

データ登録・編集画面でこのクラス自体を項目として入力することは基本的に使用しません。関連するプロパティを入力すると、必要な構造はバックエンド側で管理されます。

## 関連用語

- `dwc:Occurrence`：オカレンス
- `dwc:Identification`：同定
- `dwc:Event`：イベント

## 別名（日本語）
