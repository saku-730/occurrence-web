# fromLithostratigraphicUnit

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/fromLithostratigraphicUnit`

ラベル
`From Lithostratigraphic Unit`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

Use to link a dwc:GeologicalContext instance to an IRI-identified lithostratigraphic unit at the lowest possible level in a hierarchy.

- 日本語訳 -

由来岩相層序単位を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

通常の文字入力では基本的に使用しません。外部リソースの URI を値として登録・編集する必要がある場合に使用します。

## 関連用語

- `dwc:scientificName`：学名
- `dwc:occurrenceID`：オカレンス識別子
- `dwc:basisOfRecord`：記録根拠
