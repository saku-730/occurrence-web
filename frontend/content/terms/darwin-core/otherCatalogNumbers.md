# otherCatalogNumbers

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/otherCatalogNumbers`

ラベル
`Other Catalog Numbers`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A list (concatenated and separated) of previous or alternate fully qualified catalog numbers or other human-used identifiers for the same dwc:MaterialEntity, whether in the current or any other data set or collection.

- 日本語訳 -

試料・標本に関するその他の目録番号を記録するための用語です。

## 説明

その他の目録番号の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面でその他の目録番号を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:MaterialSample`：試料試料
- `dwc:catalogNumber`：目録番号
- `dwc:institutionCode`：機関コード
