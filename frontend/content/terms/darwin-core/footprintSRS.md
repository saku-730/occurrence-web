# footprintSRS

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/footprintSRS`

ラベル
`Footprint SRS`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

The ellipsoid, geodetic datum, or spatial reference system (SRS) upon which the geometry given in dwc:footprintWKT is based.

- 日本語訳 -

採集・観察地点に関する範囲の空間参照系を記録するための用語です。

## 説明

範囲の空間参照系の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で範囲の空間参照系を記録する必要がある場合に、項目名として選択して値を入力します。
