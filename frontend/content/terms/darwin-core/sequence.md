# sequence

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/sequence`

ラベル
`Sequence`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A string representing nucleotide base pairs.

- 日本語訳 -

メディア又は配列データに関する配列を記録するための用語です。

## 説明

配列の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で配列を記録する必要がある場合に、項目名として選択して値を入力します。
