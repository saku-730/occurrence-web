# organismInteractionDescription

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/organismInteractionDescription`

ラベル
`Organism Interaction Description`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A verbatim description of a dwc:OrganismInteraction.

- 日本語訳 -

地質学的文脈に関する生物個体相互作用説明を記録するための用語です。

## 説明

生物個体相互作用説明の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で生物個体相互作用説明を記録する必要がある場合に、項目名として選択して値を入力します。
