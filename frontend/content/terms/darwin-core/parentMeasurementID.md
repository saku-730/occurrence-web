# parentMeasurementID

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/parentMeasurementID`

ラベル
`Parent Measurement ID`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

An identifier for a broader dwc:MeasurementOrFact that groups this and potentially other dwc:MeasurementOrFacts.

- 日本語訳 -

測定結果に関する親測定識別子を記録するための用語です。

## 説明

親測定識別子の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で親測定識別子を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:measurementType`：測定種別
- `dwc:measurementValue`：測定値
- `dwc:measurementUnit`：測定単位
