# verticalDatum

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/verticalDatum`

ラベル
`Vertical Datum (IRI)`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

The vertical datum used as the reference upon which the values in the elevation terms are based.

- 日本語訳 -

鉛直基準面を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

通常の文字入力では基本的に使用しません。外部リソースの URI を値として登録・編集する必要がある場合に使用します。

## 関連用語

- `dwc:verticalDatum`：鉛直基準面
- `dwc:scientificName`：学名
- `dwc:occurrenceID`：オカレンス識別子
