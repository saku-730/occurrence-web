# institutionCode

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/institutionCode`

ラベル
`Institution Code`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A name (or acronym) in use by an institution having custody of a resource.

- 日本語訳 -

試料・標本に関する機関コードを記録するための用語です。

## 説明

機関コードの値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で機関コードを記録する必要がある場合に、項目名として選択して値を入力します。
