# decimalLatitude

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/decimalLatitude`

ラベル
`Decimal Latitude`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A geographic latitude (in decimal degrees, using the spatial reference system given in dwc:geodeticDatum) of a dcterms:Location.

- 日本語訳 -

採集・観察地点に関する十進緯度を記録するための用語です。

## 説明

十進緯度の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で十進緯度を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:decimalLongitude`：十進経度
