# georeferenceVerificationStatus

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/georeferenceVerificationStatus`

ラベル
`Georeference Verification Status`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A categorical description of the extent to which the georeference has been verified to represent the best possible spatial description for the dcterms:Location of the dwc:Occurrence.

- 日本語訳 -

採集・観察地点に関する地理参照検証状態を記録するための用語です。

## 説明

地理参照検証状態の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で地理参照検証状態を記録する必要がある場合に、項目名として選択して値を入力します。

- `dwc:decimalLongitude`：十進経度
