# agentID

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/agentID`

ラベル
`Agent ID`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

An identifier for a dcterms:Agent.

- 日本語訳 -

記録に対する主張又は行為者に関する行為者識別子を記録するための用語です。

## 説明

行為者識別子の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で行為者識別子を記録する必要がある場合に、項目名として選択して値を入力します。基本的に使うことは少ないですが、生物を捕獲する際に使用したトラップのIDなど、人間以外にも使うことができます。

## 関連用語

- `dwc:assertionType`：主張種別
- `dwc:assertionValue`：主張値
