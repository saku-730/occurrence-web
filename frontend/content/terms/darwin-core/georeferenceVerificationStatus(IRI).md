# georeferenceVerificationStatus

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/georeferenceVerificationStatus`

ラベル
`Georeference Verification Status (IRI)`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

A categorical description of the extent to which the georeference has been verified to represent the best possible spatial description for the dcterms:Location of the dwc:Occurrence.

- 日本語訳 -

地理参照検証状態を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

通常の文字入力では基本的に使用しません。外部リソースの URI を値として登録・編集する必要がある場合に使用します。

## 関連用語

- `dwc:georeferenceVerificationStatus`：地理参照検証状態
- `dwc:scientificName`：学名
- `dwc:occurrenceID`：オカレンス識別子
