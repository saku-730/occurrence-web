# Event

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/Event`

ラベル
`Event`

種別
`Class`

目的語の形式: クラス

## 定義

- 原文 -

An action, process, or set of circumstances occurring at a dcterms:Location during a period of time.

- 日本語訳 -

イベントを表すクラスです。

## 説明

イベントに属する情報をまとめるための RDF クラスです。

## Bio-Databaseでの使い方

データ登録・編集画面でこのクラス自体を項目として入力することは基本的に使用しません。関連するプロパティを入力すると、必要な構造はバックエンド側で管理されます。

## 関連用語

- `dwc:Occurrence`：オカレンス
- `dwc:Identification`：同定
