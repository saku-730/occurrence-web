# bibliographicCitation

## 基本情報

IRI
`http://purl.org/dc/terms/bibliographicCitation`

ラベル
`Bibliographic Citation`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A bibliographic reference for the resource.

- 日本語訳 -

別のリソースとの関係に関する書誌引用を記録するための用語です。

## 説明

書誌引用の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で書誌引用を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:relatedResourceID`：関連リソース識別子
- `dwc:relationshipOfResource`：リソース間関係
- `dwc:resourceID`：リソース識別子
