# assertionError

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/assertionError`

ラベル
`Assertion Error`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A description of the potential error associated with a dwc:assertionValue.

- 日本語訳 -

記録に対する主張又は行為者に関する主張の誤差を記録するための用語です。

## 説明

主張の誤差の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

Bio-Database では assertion 関連の情報を扱わない方針のため、データ登録・編集画面では使用しません。

## 関連用語

- `dwc:assertionID`：主張識別子
- `dwc:assertionType`：主張種別
- `dwc:assertionValue`：主張値

## 別名（日本語）
