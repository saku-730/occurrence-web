# MachineObservation

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/MachineObservation`

ラベル
`Machine Observation`

種別
`Class`

目的語の形式: クラス

## 定義

- 原文 -

An output of a machine observation process.

- 日本語訳 -

機械観察を表すクラスです。

## 説明

機械観察に属する情報をまとめるための RDF クラスです。

## Bio-Databaseでの使い方

データ登録・編集画面でこのクラス自体を項目として入力することは基本的に使用しません。関連するプロパティを入力すると、必要な構造はバックエンド側で管理されます。

- `dwc:Identification`：同定
- `dwc:Event`：イベント
