# pathway

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/pathway`

ラベル
`Pathway`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

The process by which a dwc:Organism came to be in a given place at a given time.

- 日本語訳 -

オカレンス記録に関する経路を記録するための用語です。

## 説明

経路の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で経路を記録する必要がある場合に、項目名として選択して値を入力します。

## 関連用語

- `dwc:occurrenceID`：オカレンス識別子
- `dwc:basisOfRecord`：記録根拠
- `dwc:occurrenceRemarks`：オカレンス注記

## 別名（日本語）
