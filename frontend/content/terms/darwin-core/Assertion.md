# Assertion

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/Assertion`

ラベル
`Assertion`

種別
`Class`

目的語の形式: クラス

## 定義

- 原文 -

A statement about an rdfs:Resource (http://www.w3.org/2000/01/rdf-schema#Resource).

- 日本語訳 -

主張を表すクラスです。

## 説明

主張に属する情報をまとめるための RDF クラスです。

## Bio-Databaseでの使い方

Bio-Database では assertion 関連の情報を扱わない方針のため、データ登録・編集画面では使用しません。

## 関連用語

- `dwc:Occurrence`：オカレンス
- `dwc:Identification`：同定
- `dwc:Event`：イベント

## 別名（日本語）

- 主張
