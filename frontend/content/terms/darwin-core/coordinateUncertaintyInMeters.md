# coordinateUncertaintyInMeters

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/coordinateUncertaintyInMeters`

ラベル
`Coordinate Uncertainty In Meters`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

A horizontal distance (in meters) from a given dwc:decimalLatitude and dwc:decimalLongitude describing the smallest circle containing the whole of the dcterms:Location. Zero is not a valid value for this term.

- 日本語訳 -

測定結果に関する座標不確かさ（メートル）を記録するための用語です。

## 説明

座標不確かさ（メートル）の値を記録し、オカレンスの意味を明確にします。値の表記は、可能な限り標準的な形式又は統制語彙にそろえます。

## Bio-Databaseでの使い方

データ登録・編集画面で座標不確かさ（メートル）を記録する必要がある場合に、項目名として選択して値を入力します。
