# inDescribedPlace

## 基本情報

IRI
`http://rs.tdwg.org/dwc/iri/inDescribedPlace`

ラベル
`In Described Place`

種別
`Property`

目的語の形式: IRI

## 定義

- 原文 -

Use to link a dcterms:Location instance subject to the lowest level standardized hierarchically-described resource.

- 日本語訳 -

内記載場所を IRI で表すための用語です。

## 説明

同名のリテラル用語ではなく、外部語彙や別リソースを IRI で参照したい場合に使います。

## Bio-Databaseでの使い方

通常の文字入力では基本的に使用しません。外部リソースの URI を値として登録・編集する必要がある場合に使用します。

## 関連用語

- `dwc:occurrenceID`：オカレンス識別子
- `dwc:basisOfRecord`：記録根拠
