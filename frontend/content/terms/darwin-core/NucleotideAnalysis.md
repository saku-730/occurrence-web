# NucleotideAnalysis

## 基本情報

IRI
`http://rs.tdwg.org/dwc/terms/NucleotideAnalysis`

ラベル
`Nucleotide Analysis`

種別
`Class`

目的語の形式: クラス

## 定義

- 原文 -

A link between a dwc:NucleotideSequence or a dwc:Identification and a dwc:Event and a dwc:MaterialEntity from which it was derived, using a specified dwc:Protocol.

- 日本語訳 -

ヌクレオチド解析を表すクラスです。

## 説明

ヌクレオチド解析に属する情報をまとめるための RDF クラスです。

## Bio-Databaseでの使い方

データ登録・編集画面でこのクラス自体を項目として入力することは基本的に使用しません。関連するプロパティを入力すると、必要な構造はバックエンド側で管理されます。

## 関連用語

- `dwc:Occurrence`：オカレンス
- `dwc:Identification`：同定
- `dwc:Event`：イベント

## 別名（日本語）

- ヌクレオチド解析
