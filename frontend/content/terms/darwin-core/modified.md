# modified

## 基本情報

IRI
`http://purl.org/dc/terms/modified`

ラベル
`Date Modified`

種別
`Property`

目的語の形式: リテラルを主に使用

## 定義

- 原文 -

Date on which the resource was changed.

- 日本語訳 -

リソースが最後に更新された日時を表す用語です。

## 説明

更新履歴の基準となる日時を記録します。

## Bio-Databaseでの使い方

登録・編集画面では入力しません。バックエンドが更新時刻を自動で設定します。

## 関連用語

- `dwc:occurrenceID`：オカレンス識別子
- `dcterms:accessRights`：アクセス権利
- `dcterms:references`：参照
